# Structura

Модуль 1С-Битрикс для пользовательских свойств — блоков полей, которые
прикрепляются к инфоблокам, их элементам и разделам.

**Разработчик:** Ершов Вячеслав. **Проект:**
[github.com/structura-bx/structura.structura](https://github.com/structura-bx/structura.structura).
**Лицензия:** бесплатное использование в любых проектах, продажа как отдельного
продукта и конкурирующие форки запрещены — см. [LICENSE.txt](LICENSE.txt).

Свойства инфоблока плоские: строка, число, список. Как только нужен «баннер с
подписью, картинкой и цветом фона, и таких баннеров пять», штатных свойств не
хватает. Structura описывает такие структуры кодом, хранит значения в JSON и
рисует для них форму в админке.

```php
// /local/php_interface/structura/blocks/banner/config.php
use function Structura\Structura\{Block, Text, Repeater, Image, Color, Required};

return Block('Баннер')
    ->setFields(
        Text('Заголовок', 'title')->setValidation(Required()),
        Repeater('Слайды', 'slides')->min(1)->setFields(
            Text('Подпись', 'caption'),
            Image('Картинка', 'picture'),
            Color('Цвет фона', 'bg')->format('hex')
        )
    );
```

```php
// в шаблоне
$banner = Structura\Structura\Blocks::element($elementId)->block('banner');

foreach ($banner['slides'] as $slide) {
    echo CFile::ShowImage($slide['picture']);
}
```

**Требования:** PHP >= 8.0 (проверено на 8.2), 1С-Битрикс с модулем `iblock`.
Внешних зависимостей нет — composer в репозитории обслуживает только тесты.

## Установка

1. Скопируйте каталог `structura.structura/` в `/local/modules/structura.structura/`
   **или** в `/bitrix/modules/structura.structura/`
2. Установите модуль: **Marketplace → Установленные решения → Structura**.

Установщик создаёт таблицы `structura_value` и `structura_revision`,
разворачивает `/local/php_interface/structura/configuration.php` и каталог
блоков, регистрирует обработчики событий.

## Быстрый старт

> ⚠️ **Выдайте право на модуль.** Ajax-роут закрыт правом `structura`: по
> умолчанию у администратора `W`, **у остальных `D`**. Если контентом занимаются
> не админы, выдайте право их группам — **Настройки → Пользователи → Уровни
> доступа → Structura**. Иначе вкладка ответит 403, и это выглядит как поломка
> модуля.

**1. Опишите блок.** Создайте `/local/php_interface/structura/blocks/banner/config.php`:

```php
<?php
use function Structura\Structura\{Block, Text, Image, Required};

return Block('Баннер')
    ->setFields(
        Text('Заголовок', 'title')->setValidation(Required()),
        Image('Картинка', 'picture')
    )
    ->version('1.0.0');
```

Имя папки — это код блока. Регистрировать больше ничего не нужно: модуль
находит блоки обходом каталога.

**2. Заполните значения.** Откройте любой элемент инфоблока — на форме появилась
вкладка **Structura**. Добавьте блок и сохраните.

**3. Выведите на сайте:**

```php
use Structura\Structura\Blocks;

$banner = Blocks::element($elementId)->block('banner');

if ($banner !== null) {
    echo htmlspecialcharsbx($banner['title']);
    echo CFile::ShowImage($banner['picture']);
}
```


## Возможности

|                                                   |                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **26 типов полей**                | текст, числа, даты, списки, цвет, файлы и картинки, медиабиблиотека, ссылки на элементы, разделы, инфоблоки, highload-строки и пользователей —[справочник](docs/fields.md) |
| **Вложенность**                  | `Repeater` (повторяющиеся строки) и `Flexible` (строка одного из макетов) вкладываются друг в друга без ограничений                                                                                          |
| **Валидация**                      | встроенная у типов плюс свои правила; рекурсивная — путь к ошибке отражает вложенность                                                                                                                               |
| **Политики доступа**         | ограничение правки блока или отдельного поля по группам, пользователям и своим правилам                                                                                                                            |
| **История и откат**            | снапшот на каждое сохранение, лимит и TTL, откат append-only; у каждой копии блока своя история                                                                                                                               |
| **Копии блока**                   | `->multiple()`: один блок на сущности несколько раз, со своими значениями и историей                                                                                                                                               |
| **Группы блоков**               | папки с`.group.php`; `->unique()` — взаимоисключающие блоки                                                                                                                                                                                                  |
| **Публичное API**                  | чтение и запись значений из своего кода —[`Structura\Structura\Blocks`](docs/api.md)                                                                                                                                                                       |
| **События полей**               | `<блок>:<поле>:<add\|update\|delete>` на каждое изменение                                                                                                                                                                                                            |
| **Копирование элемента** | свойства переезжают на копию сами; файлы по умолчанию общие с оригиналом, полный дубль — настройкой`copy_files`                                                                                          |
| **Удаление элемента**       | значения, переводы, история и загруженные файлы уходят вместе с ним                                                                                                                                                                   |

Конфигурация **не хранится в БД** — она целиком описана файлами и версионируется
вместе с проектом. В БД лежат только значения.
